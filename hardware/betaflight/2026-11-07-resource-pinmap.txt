# What the firmware rungs use
#
# Rung 1 · blink an LED      LED 1 = PE3   (LED 2 = PE4)
# Rung 2 · USB "hello"       USB uses PA11/PA12 (fixed on every STM32H743);
#                            USB_DETECT = PE2 senses when a cable is plugged in
# Rung 3 · read the BMI270   the active gyro is slot 2 (diff all: gyro_1_enabled = OFF)
#                            chip select  GYRO_CS 2   = PE11
#                            data-ready   GYRO_EXTI 2 = PE15
#                            bus: very likely SPI4 (SCK PE12 · SDI/MISO PE13 · SDO/MOSI PE14),
#                            same port E block. Unconfirmed: check with CLI `get gyro_2_spibus`
# Rung 4 · DShot to motor 1  MOTOR 1 = PB0. DShot also needs the timer and DMA
#                            channel behind that pin: CLI `timer` and `dma` show them
# Rung 5 · radio (CRSF)      the receiver goes on a UART; pick one and its TX/RX pair above
# Battery voltage / current  ADC_BATT = PC0 · ADC_CURR = PC1
# Buzzer                     BEEPER = PB3
