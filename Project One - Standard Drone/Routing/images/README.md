# Routing/images/

Build photos taken during the work instructions. **Your own pictures** — unlike
[reference/](../../../reference/), nothing here is someone else's material.

## Naming

`wi<NN>-<subject>-<NN>.jpg` — the WI it belongs to, then what it shows. A photo
that doesn't say which WI it came from is a photo nobody will look at again.

## Worth photographing

- Anything you had to **redo** — the failure is more useful than the success
- Every **CHECK** that's easier to show than describe (joint quality, wire routing)
- Screen captures of charger / Betaflight readings, with the numbers legible
- The state of the bench at the end of a session, so the next one starts oriented
